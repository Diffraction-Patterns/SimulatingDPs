# Simulating Diffraction Patterns
This project is dedicated to assisting with diffraction patterns

## Core functionalities
1. Calculates the (reciprocal) metric tensor for a lattice of a crystal
2. Calculates planes given a zone axis direction

## Current state
At its current implementation, given an input of:
- Lattice (a, b, c, alpha, beta, gamma)
- Zone Axis Direction (i.e. 101 format) 
It will output the calculations of:
- the two smallest planes
- their magnitudes
- the angle between
